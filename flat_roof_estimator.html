Job Information
Tape Defaults — context: Soprema SBS
Pick the default Fire Tape and Lap Tape products for the active BoD tab. When you add a secondary board with a non-zero fire/lap LF multiplier to a system, tape rows auto-generate using these products. Tape defaults persist per BoD — switching the BoD tab in the System Builder swaps the dropdowns to that BoD's tape products. Both must be set for auto-tape to fire.
Roof Areas
Add a tab for each separate roof on this job (e.g. Main building, Penthouse, Garage). Quantities are summed across all areas at calculation time.
Markup & Margin
Roofing System Builder
Build a complete system for the customer. Add multiple system options to give the customer choices (e.g. Good / Better / Best). Each system is quoted independently and compared side-by-side.
Basis of Design
Switches which manufacturer's products show in the system builder dropdowns. "All Manufacturers" shows everything for cross-shopping. Tape Defaults auto-switch per BoD.
Job Costs & Site Expenses
Travel, crane, fuel, delivery — counted separately from materials.
Labour
Crew roster + phase-based hours. OT (1.5×) auto-calculated for hours over 8/day per employee.
